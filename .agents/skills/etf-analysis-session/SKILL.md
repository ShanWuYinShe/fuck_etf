# ETF 分析会话标准流程

搜集消息面 + 结合持仓/自选 + 分析未来几日走势 + 给今日最优操作，每轮按此顺序执行（脚本只采集、AI 只分析，禁止自动下单）：

1. 采集：python3 scripts/fetch_etf_data.py（盘后只刷消息面用 --news-only；午休 11:30-13:00、收盘后暂停采集）。
2. 读持仓/自选：config/holdings.json + config/etf_list.txt（唯一数据源，兼容根目录，禁止用旧快照；持仓成本/份额/可卖以该文件为准）。
3. 消息面前置：读 news_merged.json（十一源合并去重，取最新 30 条）+ news_ann.json（重仓股近 3 天公告）；滞后先 --news-only 刷新；按 PROMPT_full 思路对持仓/待交易品种做主动联网搜索补充（半导体/黄金/创新药/通信等）。
4. 板块走势判定（2.1）：读 boards_up.json + boards_down.json（行业板块前 10 强/10 弱，data.diff[] 中 f14 板块名、f3 涨跌幅、f62 主力净流入；非交易时段 f3=0、f62=- 属正常），把每只持仓/自选映射到所属板块得强度三级（强/中/弱/退潮），叠加到大盘环境与个股前瞻。
5. 大盘环境判定（8.1）：index_realtime.txt + index_kline_开头的 json 算 20 日线得正常/谨慎/保守，写在输出最上方。
6. 趋势前瞻（5.3）：对每只持仓/自选给 2-5 日预判（方向 / 低吸区 / 目标区 / 时间窗 / 证伪信号），以消息面 + 趋势结构 + 板块强度三要素推导，买卖方向由前瞻决定、盘面只定择时；板块退潮的品种方向降级、低吸区下移/目标区下调。
7. 今日操作：按环境定仓位上限，持仓优先高抛低吸做T压成本（成对买卖两腿 + 价差元 + 盈亏比≥1）/ 反弹减仓 / 结构位兜底止损，输出 7.1 下单清单（代码+名称+方向+挂单价+数量+单型+止损+目标+盈亏比+触发条件）。T+1 卖出腿数量≤当日可卖份额。
8. 收盘复盘：预判校准表（10.1，兑现/偏离/失效/到期）+ 给用户 holdings.json 更新建议（AI 不代写）+ 明日预案。
9. 文档维护：分析框架/流程变动更新到项目 AGENTS.md 或 PROMPT_full.md；策略规则以 PROMPT_full.md 为准，AGENTS.md 只记本机执行流程与速览。
