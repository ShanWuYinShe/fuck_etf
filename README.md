# ETF 分析流程（v2.0 交易辅助 + 2 周波段 / 长线）

本目录包含两套可复用流程：

1. **v2.0 交易辅助（PROMPT.md 规范）**：盘中/收盘实时分析，输出 T+0/T+1 模式判定、VWAP、操作指令（同花顺下单）、消息面、持仓跟踪与大盘板块总结。
2. **2 周波段 / 长线分析**：输入代码列表 → 拉取日/周/月线 → 计算指标 → 合成**2 周波段**/长线信号 → 输出报告。

## 快速使用

```bash
# 1. 拉取数据（需联网；etf_list 中每行一个 6 位代码）
./fetch_etf_data.sh          # v2.0 采集：实时三源 + 分时(VWAP) + 日/周/月线 + 快讯 + 指数 + 板块

# 2. v2.0 盘中/复盘分析（输出到 .workwork/report/intraday_latest.md）
python3 intraday_etf.py

# 3. 生成 2周波段/长线报告（输出到 .workwork/report/，含 Markdown / HTML / JSON）
python3 analyze_etf.py

# 也可以只分析指定代码
python3 analyze_etf.py --codes 159831,515050
python3 intraday_etf.py --codes 159831,159691
```

### 推荐强势候选

```bash
# 扫描全市场 ETF，推荐短线强势且未记录的代码
python3 recommend_etf.py                  # 默认推荐 10 只
python3 recommend_etf.py --top 15         # 推荐 15 只
```

输出在 `.workwork/report/recommend.md` 和 `recommend.json`。

### 一键全流程

```bash
./run_all.sh
```

依次执行：v2.0 采集 → 分析已记录 ETF → 扫描推荐新标的 → 生成 2 周波段操作清单 → v2.0 盘中/复盘分析。

### 盘中监控（v2.0 运行纪律）

```bash
./monitor.sh        # 盘中每 2 分钟采集一轮（仅采集，不分析），午休与收盘后自动暂停
./monitor.sh --once # 只采集一轮
```

监控只做数据采集；分析由人工（或 Codex 任务）读取 `.workwork/data/` 后执行，禁止全自动下单。

## v2.0 交易辅助说明

完整规则见 [PROMPT.md](PROMPT.md)，核心要点：

- **数据源**：腾讯实时（主）+ 新浪/东财（校验，差值>0.5% 取中位数）；分时 VWAP = 最后一分钟累计成交额 ÷ (累计成交量×100)；日K 提取昨低、5日低、10日低/高。
- **模式判定**：T+0（黄金/港股/跨境等）与 T+1 采用不同量化阈值，见 PROMPT 第二节。
- **操作指令**：按强势/震荡操作表生成「去交易 / 条件单 / 双向单」建议，强制校验最小价差≥0.08%、止损上限（T+0 -1% / T+1 -1.5%）、单笔≥300元手数。
- **持仓跟踪**：编辑 `.workwork/holdings.json`（成本/止损/减仓/加仓/止盈），脚本输出当前浮盈与处理线状态。默认内置 PROMPT 第七节的 159516、159691 两条。
- **消息面**：读取新浪 7x24 最近 30 条快讯，按关键词过滤并初判利多/利空（规则初判，需人工复核）。
- **日历提醒**：CPI（每月第二周周三晚 20:30，提前 1 天）、PPI（第二周周四）、FOMC 会议（前 3 天每日提醒；2026 日期已按美联储官网安排写入脚本）。
- **输出**：每只一行模板（代码/名称/现价/区间/均价/模式/信号/操作+价位+预期涨幅+触发条件+单型），末尾含大盘板块总结（≤150字）与自检清单。

## 数据说明

- K 线数据源：腾讯行情接口（实时行情 + 分时 + 日/周/月前复权 K 线，各 640 根，约 2.5 年），目前最稳定。
- 实时行情三源：腾讯 `qt.gtimg.cn`（主）、新浪 `hq.sinajs.cn`（备）、东方财富 `push2.eastmoney.com`（校验）。
- 快讯：三源合并去重——新浪 7x24、东方财富 7x24、同花顺（最近 30 条，标注来源）。
- 外盘：美股/港股指数（腾讯）+ 美股期货/黄金/原油/汇率（新浪），用于晨间预案。
- 份额/重仓：东方财富 `stock/get`（总份额，本地缓存算每日变化）+ 天天基金移动接口（季报重仓股）。
- 大盘：上证/创业板实时行情 + 东方财富指数日K（含成交额，用于对比前日）。
- 板块榜：东方财富行业板块（最强/最弱各前 10，按涨跌幅）。
- 全市场 ETF 列表：东方财富主/备用域名 → 新浪财经 ETF 行情节点 → 本地缓存，三级回退。
  - 东财列表约 1290 只，主域名可能限流；新浪约 1624 只且包含商品 ETF（如 159831），可作独立校验。
- 个别标的不提供前复权数据时自动回退到未复权，报告内不特殊标注，请留意。
- 每根 K 线字段：日期、开盘、收盘、最高、最低、成交量（手）。

## 分析框架

### 短线波段（2 周左右）

四个维度打分，总分 −6 ~ +6：

| 维度 | 指标 | 加分 | 减分 |
|---|---|---|---|
| 趋势 | MA10/MA20 排列、MA10 斜率 | 多头排列、MA10 上行 | 空头排列、MA10 下行 |
| 动量 | 快 MACD(6,13,5)、RSI6 | DIF>DEA 金叉状态 | 死叉状态；RSI6≥70/≤30 提示超买超卖 |
| 量能 | 5 日均量 / 前 20 日均量 | ≥1.2 放量 | ≤0.8 缩量 |
| 位置 | 距 10 日高点 | ≥−2% 贴近高点 | ≤−8% 远离高点 |

档位：≥+3 强势 / +2 偏多 / +1 震荡偏多 / 0 方向不明 / −1 震荡偏弱 / −2 偏弱 / ≤−3 弱势。

### 长线（6 个月以上）

三个维度打分，总分 −4 ~ +3：

| 维度 | 指标 | 加分 | 减分 |
|---|---|---|---|
| 周线趋势 | MA10/MA30/MA60 排列 | 多头排列 | 空头排列 |
| 月线趋势 | MA12/MA24 排列 | MA12>MA24 | MA12<MA24 |
| 位置 | 52 周分位 | ≤30% 低位 | ≥75% 高位 |

档位：≥+2 偏强 / +1 中性偏强 / 0 中性 / −1 中性偏弱 / ≤−2 偏弱。

## 推荐功能原理（recommend_etf.py）

两级筛选：

1. **实时快筛**：拉取全市场约 1300 只 ETF（东方财富列表，主域名失败自动切备用域名、再回退本地缓存），过滤条件：排除 `etf_list` 已记录代码、成交额 ≥ 3000 万、当日上涨；按当日涨幅排序，同主题最多保留 2 只，取前 40 只作为精算候选。
2. **日线精算**：对候选逐个拉腾讯日线，计算与 `analyze_etf.py` 一致的 2 周波段分（MA10/20 排列、MA10 斜率、快 MACD(6,13,5)、RSI6、量比、距 10 日高点，−6 ~ +6），另加动量延续分（0 ~ +4）：站上 MA5/MA10、快 MACD 柱为正且扩张、量能放大、10 日动量为正。

推荐门槛：短线分 ≥ 2 且延续分 ≥ 2（不足时放宽到 ≥ 1），按综合分降序取 Top N。

**类型排除**：除代码去重外，还会按 ETF 名称归一化类型（如“金/黄金/黄金股→黄金”“稀有金属/有色/稀土→有色金属”“芯片/半导体→芯片半导体”），同类型一律不推荐；已记录代码名称优先从腾讯实时行情获取（东财列表可能缺商品 ETF）。

注意：

- “推荐”基于**动量延续假设**，是强势候选而非确定性预测，尤其连续大涨后存在超买回调风险（如 RSI≥70 会在理由中提示）。
- 若某天某一板块集体大涨，推荐可能集中在同一方向，属于当日行情的真实反映；使用时请自行评估板块集中度。
- 实时列表接口可能限流，脚本会自动切备用域名；仍失败时使用最近一次成功缓存并提示时间。

## 输出结论的固定格式

对每只 ETF 按下述模板给出结论，保证可横向比较：

```text
代码 名称（最新收盘 / 数据日期）
- 短线波段（2 周左右）：档位（得分）；一句话操作思路；入场/止损/目标参考位
- 长线（6 个月以上）：档位（得分）；一句话操作思路；分批/持有/回避依据
- 风险：波动率、距高点回撤、量能异常等需要提示的点
```

## 复核清单（每次分析后必查）

1. 数据日期是否为最近交易日，停牌/缺数据代码是否已跳过并说明。
2. 名称与代码是否匹配（与实时行情返回的名称核对）。
3. 关键价位是否合理（支撑 < 现价 < 阻力，否则检查计算）。
4. 极端指标（年化波动 >80%、量比 >3、单日 >10%）是否有行情背景佐证。
5. 结论必须区分“数据事实”和“规则话术”，不得把信号分数直接当作收益承诺。

## 注意事项

- 本流程仅覆盖技术面，不含基本面、资金面、消息面；重要决策请补充行业与政策分析。
- 波段信号滞后于价格，波动大的科技类 ETF（半导体、芯片）日波动可达 7%+，止损参考（跌破 MA10 或 2×ATR）必须严格执行。
- 2 周波段以 MA10/快 MACD 为主要依据，单周横盘震荡时信号会频繁切换，适合按纪律执行而非频繁猜测。
- 输出仅作研究参考，不构成投资建议。
